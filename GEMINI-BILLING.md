# Gemini API — биллинг и квоты (инструкция оператора)

Все AI-вызовы Persona.Credit идут server-side через один ключ `GEMINI_API_KEY`
(модель **gemini-2.5-flash** во всех четырёх функциях). Ключ создаётся в
Google AI Studio: https://aistudio.google.com/app/apikey

## Сколько вызовов стоит один прогон

На одну полную оценку заявителя приходится:

| Этап | Функция | Вызовов |
|---|---|---|
| Валидация каждого загруженного файла | `/api/validate-file` | 1 × на файл |
| Извлечение данных из каждого файла | `/api/extract-document` | 1 × на файл |
| Скоринг-агенты (identity / financial / fraud / country / behavioral) | `/api/run-agent` | 5 |
| Финальная сводка | `/api/synthesize` | 1 |

Типичный прогон с 2 документами = **10 вызовов** (2+2+5+1). Документы —
самая тяжёлая часть по токенам (файл уходит в модель целиком).

## Free tier против платного

Бесплатный уровень gemini-2.5-flash имеет лимиты **на минуту и на день**
(точные цифры Google периодически меняет — актуальные см.
https://ai.google.dev/gemini-api/docs/rate-limits). Практические следствия:

- Один пользователь, делающий прогон, почти наверняка упрётся в лимит
  «запросов в минуту»: 5 агентов уходят параллельно. Симптом — ошибка **429
  RESOURCE_EXHAUSTED** в ответах API и «зависший»/упавший этап анализа в UI.
- Дневной лимит free tier исчерпывается за считанные публичные прогоны.

**Для публичного запуска free tier непригоден — включите биллинг заранее.**

## Как включить биллинг

1. https://aistudio.google.com/ → API Keys → у вашего ключа нажмите
   **Set up Billing** (привяжется проект Google Cloud).
2. В Google Cloud Console у проекта должен быть активный billing account
   (Billing → Link a billing account).
3. После включения ключ автоматически переходит на платные лимиты
   (сотни запросов в минуту) — код менять не нужно.

## Ориентир по стоимости

gemini-2.5-flash тарифицируется за токены (вход/выход раздельно; актуальный
прайс: https://ai.google.dev/pricing). Грубая оценка одного прогона с двумя
банковскими выписками по 5–10 страниц — **единицы центов США** (порядка
$0.01–0.05). При 1,000 прогонов в месяц это единицы–десятки долларов.
Точную цифру после запуска смотрите по факту (ниже).

## Мониторинг и защита от сюрпризов

- Расход по ключу: AI Studio → Usage, или Google Cloud Console → Billing →
  Reports (фильтр по «Generative Language API»).
- Поставьте **Budget alert** в Cloud Console (Billing → Budgets & alerts),
  например $25/мес с уведомлением на email — сюрпризов не будет.
- Квоты и их повышение: Cloud Console → IAM & Admin → Quotas
  (сервис «Generative Language API»).

## Симптомы проблем и что делать

| Симптом | Причина | Действие |
|---|---|---|
| 429 RESOURCE_EXHAUSTED | упёрлись в RPM/дневной лимит | включить биллинг; повторить прогон через минуту |
| 400 API key not valid | ключ не задан/отозван | проверить `GEMINI_API_KEY` в Vercel env |
| 503 / UNAVAILABLE | перегрузка на стороне Google | повторить позже; код уже не роняет весь прогон из-за одного агента |

Ключ живёт только в env Vercel-функций и в браузер не попадает.
